# Enhanced Roman Order Block

Advanced Order Block indicator for TradingView with mitigation options, higher timeframe confirmation, size filtering, alerts, and more.


## Features
- Bullish & Bearish OB detection
- Wick / Close mitigation toggle
- Minimum OB size filter (ATR based)
- Optional higher timeframe confirmation
- Extend boxes/lines customizable bars
- Max OBs limit + cleanup
- Formation & mitigation alerts

## Usage
1. Open Pine Editor in TradingView
2. Paste the content of `Enhanced-Roman-Order-Block.pine`
3. Save → Add to Chart

## Settings
- Show Bullish / Bearish / Mitigated OBs
- Mitigation Type: Wick or Close
- Min OB Size (ATR × multiplier)
- Lookback candles
- etc.
